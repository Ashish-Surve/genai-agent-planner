## Layer Responsibilities

1. **Presentation Layer**: User interface and interaction (Streamlit)
2. **Application Layer**: Agent orchestration and session management (LangGraph)
3. **Service Layer**: Business logic and domain rules
4. **Data Access Layer**: Repository pattern and external integrations
5. **Persistence Layer**: Data storage (SQLite, JSON, Apple APIs)
